# О библиотеке

**McProtoNet** — открытая библиотека на C# для протокола Minecraft Java Edition, сторона клиента. Две цели: **одна кодовая база на много версий игры** и **высокая пропускная способность** — сжатие libdeflate, аппаратный AES для шифра потока, `Span<byte>` на всём горячем пути, асинхронный ввод-вывод.

## Что получаете

- **Протокол, а не игра.** Подключиться к серверу, отправлять и принимать типизированные пакеты, включать сжатие и шифрование. Библиотека — основа для ботов, своих клиентов и инструментов.
- **Много версий, один API.** Протоколы 735–776 (Minecraft 1.16 → 26.2). Каждый пакет знает свою раскладку по версиям; версию протокола вы выбираете один раз, при подключении.
- **Оффлайн-серверы.** Handshake и login на серверы в offline-режиме из коробки; машина состояний входа остаётся в вашем коде, поэтому нестандартные серверы — не тупик.
- **Сетевые помощники.** Поиск SRV-записей и обнаружение LAN-серверов.

## Установка

```
dotnet add package McProtoNet --prerelease
```

Дальше — [Первый бот за 15 минут](getting-started.md).

## NuGet-пакеты

| NuGet-пакет | Что внутри |
| --- | --- |
| `McProtoNet` | Клей: `MinecraftClient`, типизированный `SendAsync<T>`, SRV, LAN |
| `McProtoNet.Transport` | Байты между сокетом и пакетом: кадры, сжатие, шифрование |
| `McProtoNet.Protocol` | Пакетный слой: сгенерированные классы пакетов, реестр, диспетчер, базы обработчиков |
| `McProtoNet.Primitives` | Примитивный читатель/писатель, буферы, `IncomingPacket` / `OutgoingPacket` |
| `McProtoNet.NBT` | Разбор и запись NBT |
