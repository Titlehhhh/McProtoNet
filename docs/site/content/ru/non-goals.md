# Чего библиотека не делает

McProtoNet берёт на себя протокол: кадры, сжатие, шифрование, сериализацию каждого пакета, мультиверсию и низкоуровневое чтение и запись. Кое-что остаётся за вами — намеренно, и в ближайшее время в библиотеку не переедет.

## 1. Игровая логика и ИИ

Библиотека не принимает решений за вас:

- как двигаться по миру (поиск пути, обход препятствий);
- когда атаковать моба или взаимодействовать с блоком;
- как реагировать на события (чат, игровая механика).

Поведение бота или клиента — ваш код.

## 2. Интерфейс пользователя

Нет окон, кнопок и 3D-отрисовки. Нужна оболочка вокруг бота — приносите свою; библиотека работает под капотом.

## 3. Интеграции с другими API

Не входит:

- разбор данных сторонних сервисов (карты, плагины);
- API модов (Forge, Fabric);
- базы данных для игровых данных.

## 4. Готовые решения популярных задач

Здесь нет:

- шаблонов автофермы или PvP-бота;
- алгоритмов поиска руды или строительства;
- эмуляции игровых действий из коробки (крафт, торговля с жителями).
