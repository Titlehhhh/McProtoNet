# Support the project

McProtoNet is free and open source. A donation is voluntary: it buys no
priority in issues and no private support. It pays for the time the library
takes.


The same address also takes TRX.

## TON and USDT, TON network

```text

```

TON and USDT go to one address here; the coin is chosen in the wallet.

## BTC, Bitcoin network

```text
bc1q3ushl443q9xvclxtqxcvltdd64ffy3h8x7xsm4
```

A native segwit address. The network fee is charged per transfer and does
not depend on the amount, so small donations are better sent through TRON
or TON.

## Before sending

Send only in the network named above the address. A transfer that arrives
through another network cannot be returned.

Neither address needs a memo or a tag.
