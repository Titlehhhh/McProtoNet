# Словарь

Слова, которыми пользуются API и этот сайт, в том порядке, в каком вы их встретите. Термины протокола оставлены английскими — так они называются в коде.

## Провод и транспорт

**Кадр (frame)** — один пакет на проводе: VarInt-длина, затем тело. При включённом сжатии перед телом стоит несжатый размер; при шифровании весь поток — AES/CFB8. `McProtoNet.Transport` превращает поток сокета в кадры и обратно.

**Версия протокола (`pv`)** — число, которое клиент шлёт в handshake; оно называет формат провода. 772 — это 1.21.7–1.21.8, 776 — 26.2. Таблица — в [Первом боте](/docs/getting-started/minimal-bot). Не строка версии Minecraft и не версия NuGet-пакета.

**Порог сжатия** — задаёт сервер во время login (`LoginCompress`). Тела не короче порога уходят сжатыми; `-1` — выключено.

**`IncomingPacket`** — сырой кадр из `ReadPacketsAsync`: id пакета и байты тела. Тело — окно в буфер транспорта, живёт до следующего чтения: декодируйте до любого `await`.

**`OutgoingPacket`** — то же для отправки: id и тело; длину, сжатие и шифр добавит транспорт.

## Пакетный слой

**Фаза (phase)** — одна из `handshaking`, `login`, `configuration`, `play`. Id пакетов осмысленны только внутри фазы, поэтому каждому декоду нужна фаза. `ClientboundHandler.Phase` переключаете вы.

**Направление (direction)** — `clientbound` (сервер → вам) или `serverbound` (вы → серверу). Одно имя — разные пакеты: `AbilitiesPacket` есть в обе стороны.

**Каталог (catalog)** — все пакеты одной пары (фаза, направление), например `play.toClient`. Каталогов девять.

**Ординал (ordinal)** — плотный индекс пакета внутри каталога (0, 1, 2 …). Диспетчер и подписки используют его как индекс массива: поиск — одно чтение, не словарь. Деталь реализации: руками вы его не пишете.

**`PacketIdentity`** — имя, фаза, направление и ординал типа пакета, доступны статически как `SomePacket.Identity`.

**Диспетчеризация (dispatch)** — id → ординал → декод → ваш обработчик, сгенерированным кодом (`PacketFlow.Dispatch`, `ClientboundHandler.HandleAsync`). Без рефлексии и боксинга: тип пакета известен в каждой точке вызова.

**База обработчика (handler base)** — `ClientboundHandler` / `ServerboundHandler`: сгенерированные абстрактные классы с одним виртуальным `On<ИмяПакета>` на пакет. Переопределяете нужное; незнакомые id идут в `OnUnknown`.

**Визитор (visitor)** — `IPacketVisitor`: нижний уровень (`Visit<T>(T packet)`), который зовёт диспетчер; база обработчика стоит на тех же таблицах. Нужен, когда один декодированный пакет надо раздать нескольким потребителям.

**Слои версий** — пакет, у которого поля различаются между версиями протокола, — один класс с nullable-группами вроде `V764_Last` или `VUntil764`; при отправке должна быть заполнена группа вашего `pv`, иначе `WrongLayerException` скажет, какая.

## Слова про скорость

**Горячий путь (hot path)** — код на каждый пакет: прочитать кадр, декодировать, раздать, записать кадр. Правило библиотеки там: ни одного выделения на пакет, кроме самого объекта пакета, без рефлексии, без боксинга, совместимо с AOT.

**Примитивный читатель / писатель** — `MinecraftPrimitiveReader` / `MinecraftPrimitiveWriter`: VarInt, строки, NBT, UUID и прочее поверх `Span<byte>`; из них собран каждый сгенерированный `Read` / `Write`.
